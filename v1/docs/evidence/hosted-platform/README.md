## Limits

HTTPS and localhost have separate browser storage; recipes require explicit
export/import. Returned bitmaps and linked metadata were a separate browser
proposal store, not automatically migrated or remotely generated by hosting.
This checked catalogue had111 defined contracts/six drafts and five branches
without executable domain contracts. Eleven headings did not establish full
genomic implementation, broad organism range or finished art. The
[workbench guide](../../../prototype/generator-workbench/README.md) owns current
coverage; the [gateway guide](../../../prototype/platform-server/README.md)
owns routing and retention boundaries.
