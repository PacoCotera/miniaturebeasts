## Target and delivery limits

Linux x86-64 native simulation is verified. Raspberry Pi 4 ARM/physical runtime
is not established by that build. Companion and Dock use the existing ESP-IDF
ESP32-S3 shared-UI compilation gate; compilation is distinct from a complete ESP
game, physical radio or display-runtime proof. No framework is bypassed or new
provider/environment introduced in this increment. [Architecture](../../../native/ui/README.md#screen-coverage-and-target-evidence)
owns the target distinctions.

This correction makes current paid findings and comparisons easier to inspect.
It does not establish an enjoyable discovery minigame or greater sample content
variety. [Research trial](../../../design/research-and-creation.md#remaining-design-work)
owns the next gameplay question. [Product status](../../../STATUS.md) and the
[deployment changelog](../../../CHANGELOG.md) separate review from actual sandbox
activation. Required target CI remains the release gate.
