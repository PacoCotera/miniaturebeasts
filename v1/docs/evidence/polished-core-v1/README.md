This packet records C17 host frames and depicted-control input across Companion,
Lab and Dock, using isolated saved worlds and real timers. It establishes one
connected Pip journey and subsequent source-pinned screen corrections. It does
not establish ARM/MCU runtime, physical radio/display behavior or human enjoyment.
Some gathering screens show the earlier timed fixture; [current play](../../../native/selected-lab/V1.md)
uses finite immediate whole offers. Native release identity is recorded separately
in [status](../../../STATUS.md) and [deployment changelog](../../../CHANGELOG.md).

## Behavior established

The Field haul survives leaving reception through Home. Acceptance credits whole
stock once, clears current Cargo and ends the expedition. Sample A retains its
paid inheritance/movement/coat findings; a reversible supported-form draft leads
to a separate five-of-each creation commitment and deliberate reveal. Lab and
Companion visits reach the same saved resident/count, also projected on Dock.

Offline Companion and Dock retain dated snapshots through restart. Unavailable
care queues nothing; reconnect preserves identity, original portrait and count.
Garden sample B takes an effort-first path, permits free known Movement inspection
and supports B1. B1 is a distinct resident sharing A0's permitted carried portrait.
Shared art does not merge individual identity.
