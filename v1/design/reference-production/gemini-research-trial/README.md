# Research-sprite method trial

This experiment compares two browser-generated Research destination symbols at a136×144 usage footprint. It asks whether the subject remains clear and material drawing survives reduction. Both results are preserved concept studies; neither is a native master.

![Intended-size comparison](comparison.png)

Inputs were the [C18 crop](../../game-art-proposals/37-lab-extracted-kit/screen-reference.png), an [Overview placement reference](../exports/overview-populated.png), and [prompt](prompt.txt). The observed browser chat mode was3.1Pro. One initial result and one visible Redo with Pro result do not form a controlled model benchmark.

The original `*-copied.png` files are1024×559 opaque PNGs obtained through Copy image. A larger download was reported but not recovered. [inspection.json](inspection.json) records hashes, crop rectangles and usage transformations. `inspect.cjs` uses the existing Node/Sharp runtime to crop and resample; it neither redraws nor removes backgrounds.

The initial result has clear glass modeling, but its droplet overlaps Essence's resource identity and DNA suggests specimen content in an empty destination. The redo has richer brass/glass but loses clarity among small screens, tubes and accessories. It reads as a miniature apparatus already in use.

Acquisition succeeded; empty-state meaning, native-size craft and transparent asset production remain unresolved. Provider transport cannot be inferred to solve those art problems. These findings concern this browser source method, rather than the separate [game-creature rendering contract](../../../prototype/generator-workbench/rendering-contract.md).

Source documentation: [Gemini Apps image generation](https://support.google.com/gemini/answer/14286560?hl=en-IN), [API image models](https://ai.google.dev/gemini-api/docs/image-generation?authuser=00), and [API thinking controls](https://ai.google.dev/gemini-api/docs/thinking). API settings do not establish equivalent controls in the observed browser session.
