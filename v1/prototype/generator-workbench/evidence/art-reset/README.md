# Art-first pet calibration

One reversible visual proposal: a cohesive pet and two related genomic variants. The family explores pet portrayal beyond the diagnostic diagram. No generator implementation or game deployment is included.

The [original Companion concept](../../../../design/companion-promise/field-partner-concept.png) supplies friendly character presence and HiBit craft. It does not select a species, body preset or hardware behavior. The [proposed phenotype](phenotype-proposal.json) fixes body organization, face, appendage roles/counts, proportions, pigments and coverings; continuous tissue contour, light and fine pixel detail belong to depiction. These are proposed semantic inputs, not outputs of the current engine.

## Corrected result and review

The latest critters are preferred references, alongside [this Midjourney animation](owner-midjourney-animation.gif) of the initial family. [Its manifest](owner-midjourney-animation.json) retains the original GIF hash and frame/timing metadata. This provides a supplied illustration-to-animation reference, not a proven current-engine genome-to-animation pipeline; temporal anatomy/identity fidelity remains to be reviewed. Workbench usability and its diagnostic diagrams were separately rejected.

[Corrected raster 02](gemini-family-02.png) and [its browser capture](gemini-browser-02.jpg) retain the actual second Gemini response. The correction removed text and added richer fur clusters. All three still read as related pets, with visible longer limbs/larger face in the center and feather covering on the right. It restored the cream chest on the first two only.

Independent art and genetics inspection agree: this is useful for character/style review, but **brief fidelity remains HOLD**. The feather subject still lacks the invariant cream chest pigment. Foot striations on the fur subjects could be read as digits, which were not specified. Exact face/body ratios and complete attachment geometry are not established by the images. No invented rule that feathers suppress pigmentation excuses the missing marking. Pixel detail is improved but does not yet establish the original reference's full HiBit richness.

One initial request and one bounded correction; no further retry. Images were obtained through ordinary Copy image as PNG. Full-size provider download was not obtained; backend model, cost and reproducibility are unverified. The [run manifest](run.json) records prompt/reference/output hashes and extraction limits. No art approval, engine change, native build or sandbox deployment is claimed. Stop at visual review before further generator implementation.
