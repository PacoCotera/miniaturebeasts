## Preserved five-locus Pip reference

The unchanged [Pip engine](../../genetics/README.md) has a separate diagnostic workbench reference. [Actual browser view](workbench.jpg) shows cc/mm/Ee, including a laboratory draft outside the sample's two supported founders.

Recorded checks covered the 243-genotype space, baseline-reference rejection, direct/indirect cause closure and HTTP422 recovery. Actual browser interaction exercised Pp→pp, pinned comparison, edit invalidation, unsupported juvenile context, cc/mm/Ee, and reconstruction after an imported embedded SVG was altered. Source reconstruction, rather than imported artwork, governed replay. Screenshot assessment corrected missing crown/signaling cause information.

This evidence establishes those bounded operations and browser artifacts. It does not supply general creature construction, accepted game art, incarnation, animation or device behavior.
