# Connected scene authoring proof

This reversible host experiment connects verified genetic expression to the
existing body, ocular and skin/scales constructors in the React/Mantine
workbench. It retains complete source records and separate construction,
reference and prompt identities. No image provider was called, and these SVGs
are construction previews rather than finished pet artwork.

## Retained outputs

| Input | Construction comparison | Plates |
| --- | --- | --- |
| [Single body](single-scales.packet.json) | One dominant body with six jointed appendages and optional eyes | 9 |
| [Axial body](axial-scales.packet.json) | Three connected body regions with six fins and eyes | 17 |
| [Extent variant](single-scales-extent.packet.json) | Same single-body source with wider scale coverage | 23 |

Each input has a same-named SVG and exact UTF-8 `.prompt.txt` file. The
[manifest](manifest.json) records source, construction, reference and prompt
digests. The comparison uses common framing. Newly projected
[default broad](default-broad-v3.prompt.txt) and
[second broad](broad-seed-21-v3.prompt.txt) briefs demonstrate template3 on
previous packages; historical retained records remain unchanged.

The emitted briefs use explicit pixel-art craft and compact visual proportions,
rooted roles/counts, facial availability, source pigments and actual covering
fields. Coordinates and causal traces stay in the full scene export. `#G…` and
`#E…` are declared 12-hex lookup fingerprints with full hashes retained;
they do not encode a whole genome, identify ownership or implement QR sharing.

## Generation and replay

The bounded search accepts only unmodified whole-genome candidates that pass
genetic, body, ocular and covering construction. Requested seeds1,1000 and2000
resolve at candidate seeds79,1259 and2163 after79,260 and164 total draws. These
three eligibility samples include three/five/three body regions, no/no/two fins,
zero/two/two eyes and skin/skin/scales. They do not establish general diversity
or an acceptance-rate benchmark. Exhaustion yields no substitute creature.

Full generated packets remain local; the copyable scene export sends retained
input and expected identities through the unchanged 64 KiB endpoint. The three
compact envelopes are 54,866, 54,868 and 54,868 bytes. The server reconstructs geometry instead of trusting
embedded imported artifacts. Current prompt-digest replay verifies the current
projection; it does not reproduce historical template text.

## Validation and limits

Focused integration and renderer-domain checks passed, including constructor
parity, source/result replay, identity invariants, atomic stage rejection,
common-camera world scale and actual HTTP oversize413 followed by valid replay.
The existing framework build passed. Independent technical and actual emitted
prompt reviews cover these source boundaries. Browser acceptance also passed:

- Repeated generation produced distinct valid scenes with truthful candidate
  and rejection counts. No fallback or edited-genome repair was used.
- A generated full packet's pretty JSON exceeded the existing 1 MB import guard.
  Copyable scene exports now use the compact replay envelope. The actual browser
  exported 96,395 characters and successfully reconstructed its scene and prompt
  from retained inputs; the existing local and HTTP limits stayed unchanged.
- Editing a copy cleared the previous preview and prompt and disabled Copy.
  A carried Skin copy with Scales still expressed scales; two Skin copies removed
  35 plates. Extent and scale values remained retained but became inactive.
- [Pinned comparison](browser-comparison.png) shows those three deltas at one
  common camera and world scale. [Current inspection](browser-prompt.png) shows
  the selected locus, resulting material, construction and v3 prompt pane.
- The original anatomy package still resolved with the new concise v3 prompt.

Copy displayed success in the browser. The automation session's virtual
clipboard did not match the field, so external clipboard interoperability is
not established. Exact retained prompt files were reviewed independently; no
image provider was called.

Source texture is retained in the audit and renderer prose; this scene SVG does
not draw fine ridges. Unsupported radial, membrane and branched constructions
remain rejected by this consumer. This proves neither all-locus visible
coverage nor the full desired creature range. Fur/feathers,3D,animation,
physiology,finished illustration and game/device integration remain separate.
