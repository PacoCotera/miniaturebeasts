; Mibi 7x9 master glyph source. Hand-editable: one block per glyph.
; Block = header line (U+code, the character, optional adv=N) then 9 rows of 7 characters: . empty, # ink.
; An accented letter carries its mark above the cap line in 1 or 2 extra rows on top: 10 rows for the lower-case
; acute, grave, circumflex and tilde, 11 for the accented capitals. The line pitch is 11, so those rows are the leading.
; Cell grid: columns 0-6, rows 0-8. Column 0 and column 6 are the side bearings and stay empty; ink lives in columns 1-5.
; Rows: caps rows 0-6, x-height rows 2-6, baseline under row 6, descenders rows 7-8.
; Advance = ink extent + 1 px tracking, unless adv=N is given (digits and the space). Lines starting with ; are comments.
; Build: python3 -I art/companion-48/tools/build-mibi.py   (writes mibi-7x9.png, mibi-7x9.json and the contact sheets)
; The base letters, digits and signs were drawn here by hand. The accented blocks were first set as a base letter plus a
; mark and are now plain blocks like the rest: edit any of them freely. Marks never touch a lower-case body: a two-row
; mark sits on rows -1 and 0 with row 1 clear, a dot or diaeresis on row 0. Capitals keep all seven rows and carry the
; mark on rows -2 and -1, touching the cap top (art director, 2026-10-08; see README).
; Ink widths: digits are 4 wide (adv=5), caps and m w up to 5 wide, nothing wider than column 5.
