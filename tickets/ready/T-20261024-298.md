## Goal (owner, 2026-10-24, on the play page: "screens are too small. it's ok if they are one under the other, just please make them bigger, resizable if possible, also there's no hash and timestamp for the release in the footer")
Today prototypes/play/src/shell.mjs draws the faces at k = floor(devicePixelRatio) device px per lp, so on a 1x or 1.25x display the 1024x600 Station and the Companion show at about their native pixel size, which reads small.
## Lines
1. A size factor `z`, a whole number of device pixels per lp (z = 1, 2, 3 …; k becomes z instead of floor(dpr)), so the pixel rule holds at every size: every face pixel stays a whole block of device pixels, never smoothed or fractional.
2. Default "fit": the largest z at which the layout fits the window, choosing between the existing tiers; at any window size the stacked tier (Station, then the Companion and the Caddy under it) is allowed whenever it gives a larger z than the row tier. Never smaller than today's k.
3. Resizable: a small size control in the page's top bar beside Keys (− / fit / +, showing the current "×z"), and the keys `-` and `=` (or `+`) do the same; the choice is kept per browser in localStorage (wrapped in try/catch; works without it) and "fit" clears it. When z is larger than fits, the page scrolls; it never shrinks a face below z.
4. The Caddy's e-paper and the page chrome (keys, trays, Dock) scale with z by the same rule they follow today.
5. Footer stamp: always visible (not only ?dev), at the page's foot: "build <short> · <built>" from build.json, as prototypes/compare/index.html reads it (`fetch('../../build.json', {cache:'no-store'})`); show the built time as written (UTC) plus "UTC"; if build.json is missing (local runs), show "build local". The stamp is page chrome: it never overlaps a device.
6. ?test keeps today's layout exactly (z = today's k) so the play journey and its checks are unchanged; add journey shots at z = 2 stacked and at fit on a 1920x1080 window, and a unit test for the fit choice (window sizes → tier and z).
## Rules
- Station, Companion and Caddy code are not touched; the shell only.
- Proof: play journey ok (existing shots unchanged under ?test); node --test 0 failures; face guard and public guard exit 0; a 1x screenshot at fit on 1920x1080 and on 1366x768 in the report.
