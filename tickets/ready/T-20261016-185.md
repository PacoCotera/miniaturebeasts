## Purpose
"Every genome expression yields a cute pet", and "a child that cannot be built never exists; the cross is not drawn again" (design/creatures-and-genomics.md). Measured during T-20261016-183, crosses of two valid pods sometimes fail to build:

| Species | Failed crosses |
| --- | --- |
| S08 | 12/200 |
| S09 | 9/200 |
| S13 | 10/200 |
| S16 | 14/200 |

Every other species built 0 failures in 200. So in these four species, about 5–7% of crosses make nothing.

## Facts (station-gate)
- Every failure is "region-… is not connected to region-…".
- In every failing child, putting `growth.join-throat-ratio` (the Waist) back to one parent's copies makes it build. In some failures, `region-taper`, `region-bend` or `region-longitudinal-form` also fix it.
- Each frame's viability check samples only the named pool alleles. Crossed children land on blend steps between them, which the check never tries.

## Steps
1. Extend each frame's viability check (`build-frames.mjs` / `species.mjs`):
   - crossed children, as well as pool samples;
   - every blend step of each open continuous locus, against the worst cases of the others.
2. Fix what fails in the frame itself, never in a consumer: bound the culprit loci's pools or ranges, or lock them for that species, as rule 6 does today. Never repair a genome.
3. A living mibi keeps its frame version. If a frame's pools change, bump the frame version only where the stamp's snapshot requires it, and say so.
4. Tests (`framework.test.mjs`): for each of the 16 species, N crosses of valid parents all build.
5. Agree with the game designer how a failed cross is shown, if the case is still reachable at all.
