## Purpose
A new player's Loika guide can never complete. `fieldGuide` (`prototypes/station/src/library.mjs`) builds a trait's possible looks from `possibleLooks` → `traitLooks(frame, trait)`. For the version-4 Loika, that includes the legacy "plain", which only version-3 lines can give. So plain sits in `unseen` for every player who never had a version-3 Loika, `complete` stays false, and the guide's sitting milestone can't be earned (Pillar 4).

## The rule (game designer, results/T-20261016-200-game-design.md and results/T-20261016-194-game-design.md)
- **Completion counts the frame's current looks only:** the looks a new pod of the current frame version can show. For the Loika that is 14 (6 colour, 3 pattern, 2 crest, 3 eyes). For the Tuikis's Claws, it is the three digging feet.
- **A legacy look** (one the trait's pool keeps only for inheritance: the Loika's plain, the Tuikis's hooves, webbed feet and roots) **shows as found once the player has seen it, but never counts toward completion and never shows as an empty frame to fill.**
- **A wish can pin a legacy look only once it has been seen.**

## Steps
1. Split a trait's looks into **current** (drawn by new pods of the current frame version) and **legacy** (kept in the pool for inheritance only). The genome engineer names the source: the frame's legacy allowance on the locus (T-20261016-194) and the Loika's version-3 "off".
2. In `fieldGuide`:
   - `possible` and `unseen` use the current looks only;
   - `found` also lists seen legacy looks, marked legacy;
   - `complete` and `oneFromFull` follow from the current looks.
3. In the wish picker: list a legacy look only once seen.
4. **Tests:**
   - a version-4-only Loika save with all 14 current looks seen reads `complete: true`;
   - the same save plus a seen plain still reads complete, and lists plain as found and legacy;
   - a save with plain unseen never lists it as unseen;
   - the Tuikis: the three digging feet complete Claws, and a seen hoof lists as found, legacy;
   - every other species' guide count is unchanged.

## Not in scope
- How a legacy look is drawn in the Library (it is the Library pass's);
- any frame or catalogue change.

## Done when
The tests pass, and a new-player save can complete the Loika's guide and earn its sitting.
