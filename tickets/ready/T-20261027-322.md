## Goal
Owner 2026-10-27: archive the current name suggestions and give mibis Spanish names common for pets (cats, dogs, raccoons, birds). The app stays in English; the Spanish names are a deliberate contrast.
## Lines
- One home for the name lists, read by the Station and the Companion: `es-pets-1` (current, the 256 below, in this order) and `en-short-1` (archived 2026-10-27: Dot, Moss, Bean, Fig, Nib, Tuft, Pebble, Wren, Pip, Sorrel, Burr, Quill). MIBI_NAMES (state.mjs) and the Companion's list (exploration/index.html) read the current list; nothing else in the name rules changes (nameKey, NAME_MAX 10, namesUsed, peekNames, the compound safety net).
- Saves keep their mibis' names; a new draw takes the first unused name of the current list.
- Tests, fixtures, goldens and owner layout cards that show today's names pin the archived list (inject the pool), so they keep their names; a golden changes only where a name is drawn fresh or suggested (the namer's suggestions). List each changed golden.
- Accents: the face fonts carry á é í ó ú ñ ü Á Ñ; confirm every name renders on the face and the Companion, and that the namer's accent page can type each one.
