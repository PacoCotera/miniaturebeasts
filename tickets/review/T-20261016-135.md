## Source of truth (code wins over documents)
The framework code and the frames registry (prototypes/workbench/framework/, prototypes/station/src/genome.mjs on station-gate), then design/creatures-and-genomics.md, then decisions.md.
## Steps
1. Build a mapping table, one row per framework concept, with its column on screen:
   - every layer and domain (trunk and branch loci, families, looks against doings, the chapters in their fixed order);
   - every locus kind (locked, configurable, inherited-only, self-changing, sleeping behind a switch, sealed);
   - copies and dominance (shown, hidden, carried, blend);
   - research state (read, unread, glint);
   - clash, origin, frame version.
   For each row: how the screen draws it, or "missing", or "drawn but not in the framework" (invented).
2. Run it against real frames, at least S01, S03, S09 and S12 (the smallest, the wireframe's, the deepest, the six-legged). Check the counts per chapter and that the mark kinds match the data, as the wireframe's S03 asleep error showed they can drift.
3. List every fix for UI/UX and the game designer. Where the framework itself has a gap or a conflict with the design doc, name it; the code wins.
