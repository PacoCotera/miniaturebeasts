## What changed

The game designer's call (A): a Tuikis's claws are how it digs.

- **The S03 frame, now version 5:**
  - The Claws pool (`anatomy.contact-terminal-form`) is narrowed to **rounded, pad, wedge**: "round feet", "padded feet", "digging wedges".
  - **hoof, webbed and root** are legacy alleles: legal for inheritance, never drawn for a new pod, and described plainly as "hooves", "webbed feet" and "roots".
  - It uses the per-frame version and `row.legacy` from PR 226.
- **Only this locus changed** in the S03 frame, plus its version and counts.
- **The stamp registry appends S03 v5.** v2, v3 and v4 are carried, so every print decodes. A copy still indexes the catalogue's six forms, so a legacy copy stamps and reads.
- **The field guide** counts S03 Claws as three looks. "S03:feet" comes off the Station's `FRAME_GAPS` (the ticket's step 3; one line in `prototypes/station/tests/library.test.mjs`). The list is now empty.
