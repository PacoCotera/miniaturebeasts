  - The Companion's trip record (`sv.trips[]`) carries `{ partner, places (meadow, pond, rock, wood, cave), storm (over the Probe) }`. These are exactly T-137's facts, and `mergeCare` already reads it.

  - There are ten kinds, one for each sentence it writes: grown, elder, lampLow, lampOut, herd, storm, fruit, stirring, young and quiet.
  - The place uses the trip's own vocabulary, plus shallows and cliff.
  - `lines` stays for one release so old crates still open.
- **Size:** about 100 bytes a crate as JSON (about 300 bytes for the three-crate bay), or 14 bytes packed for the relay.
- **The path:** Companion save → crate summary on the relay (still "not designed yet", design/proposals/technical-architecture.md §4.4; the Caddy passes it through unread) → the Station's summary after `seated` → `openBay` keeps it → the report draws it.
- **The Cargo card:** up to three picture rows. Each is a place badge, a change mark for the kind, the mibi's or species' face, and the count as repeated marks (at most three). There are no sentences, and an old crate shows no world block.
