## What changed
The Companion's crate carries `world: { v: 1, turn, ev }` beside `lines` (specs/world-events.md), in `prototypes/exploration/index.html`.
- **`worldTurn` returns `{ lines, ev }`**: each sentence it writes is said with its record `[kind, place, who, n]` (one helper, `say`), so the events are the lines' events: at most three, in the lines' order. The ten kinds as the spec's table: `grown` (who = mibi id, n 0 home / 1 leads / 2 can lead), `elder`, `lampLow`, `lampOut` (the outpost's land), `herd` (species index or -1, direction 1 to 8 N NE E SE S SW W NW, 0 spread out), `storm` (the main land of the charged cells; n 1 when it reached a new place, 0 for the first), `fruit` (the bloom's centre land, the bush count), `stirring` (the main land of the new pods, their count), `young` (the cell's land, species or -1), `quiet`.
- **Places**: `PLACE_KIND` = meadow, pond, rock, wood, shallows, cliff (`LAND_NAME`'s order as ids). `placePhrase` is now `placeKind` plus a phrase table with the same words ("near the cliff" is `cliff`, "by the river" is `shallows`), so the lines read as before. `mainLand` names the land most cells lie on.
- **The crate** (`endExpedition`): `lines` kept, `world` added with the crate's own turn; `rep.lines` (the Companion's own report) unchanged. A crate sealed before this has no `world` and nothing about it changes.
