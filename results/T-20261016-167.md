## What changed
- **`tools/device-sheet.py`** (Python 3 and Pillow, one command): renders every Station screen and its key states at 1x on one large PNG, in flow order (Home, Vivarium, a mibi up close, Pods, Probe bench, Create, Incubator, Cargo, Library, the decision panels). Each frame has its label inside the image (`cell id · state`), each family its heading and the head it was read from. A family wraps after `--cols` frames (default 4). Frames are never scaled: 1024 x 600 each.
- **`tools/device-sheet.json`** lists the rows and cells (39 frames) and which head each row is read from. The tool reads the committed goldens with `git show <ref>:prototypes/face/golden/<file>` (no checkout, no render): batch B-3 for the Probe bench, Create and Incubator rows (the Create bank, the Incubator ring and shadow), batch B-4 for everything else (the dock arrival, the decision panels, the Cargo report). The two heads have diverged (the 73-path merge conflict in T-20261016-147), so no single head shows the whole Station.
- **The slot for a proposed proof:** `--proof CELL=PNG` puts the PNG beside the frame it replaces, labelled `PROPOSED, beside CELL` in green. An unknown cell is refused with the list of cells. `--only Row,Row` draws some rows; `--fetch` fetches both heads first. A golden that is not found or not 1024 x 600 is listed under MISSING and the exit code is 1.
- **README line** in `README.md`.
